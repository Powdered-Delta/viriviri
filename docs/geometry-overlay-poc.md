# 视频几何与文字覆盖层原理验证

本分支 `codex/geometry-overlay-poc` 保存独立 DEBUG 实验及三种遮罩策略。
2026-10-22 用户确认 **B 符合当前验收预期**，后续主线替换以 B 为候选。
本提交保留实验现场（默认仍为原始模式），没有替换产品播放实现。

## 方案区别

| 模式 | 场景网格 | 颜色 / 深度写入 | 文字合成层 | 当前结论 |
| --- | --- | --- | --- | --- |
| 原始 `ORIGINAL` | SDK 生成 | SDK 默认策略 | 保留 | 保留 UI 后不再闪烁，但可出现漂浮黑色文字轮廓 |
| A `ALIGNED` | 以最终宽高、半径显式计算曲面三角网格 | 保留 SDK 初始化后的 alpha-punch 策略 | 保留 | 尝试对齐遮罩；未独立证明有效 |
| B `HIDDEN` | SDK 生成 | 覆盖层材质 `setColorWrite(0)`，`setDepthWrite(DISABLE)` | 保留 | 用户确认当前视觉表现符合预期 |

B 只作用于弹幕和字幕两个面板的场景材质；视频自己的场景网格、开孔和媒体
Surface 均不修改。没有通过隐藏 Entity、停止动画或关闭文字层消除轮廓。
原始/A/B 共用保留的面板、View、Display、Surface 与动画时钟。
模式切换会重建形状并重放当前几何，视频 generation 与 Surface 应保持不变。

用户同时观察到三模式存在互相影响，因此这些按钮不能被视为已验证完全独立的
实验组。代码意图通过 reshape 生成新网格恢复原始/A 的写入，但原生状态是否
完全恢复尚未确认。B 的验收不代表 A 已失败，也不证明黑轮廓的原生根因已定位。
冷启动直接进入 B 的独立验证仍需在后续收敛时完成。

## 几何与资源处理

- 三个预设：平面 1.60×0.90 m；曲面 1.60×0.90 m、r=1 m；放大曲面
  2.40×1.35 m、r=1 m。宽度滑条 1.00–2.40 m，曲率半径 0.80–3.00 m。
- 每次几何变化从最终参数直接重建视频面板；旧媒体 Surface 按身份解绑后才销毁。
  同一个播放器只 prepare 一次，不用 UV 缩放模拟几何变化。
- 弹幕、字幕保留 UI 资源，只 reshape 形状与更新位置，解决重建 UI 导致的闪烁。
- 三层中央表面固定；曲面 carrier local Z 为 base Z 减半径，平面为 base Z。
  视频、弹幕、字幕 base Z 分别为 0、-0.01、-0.02 m，zIndex 分别为 0、1、2。
- 静态锚点、控制面板与 Cozy/MediaRoom 由独立 MSE 场景拥有。动态几何由
  `GeometryExperimentActivity` 拥有；不调用产品几何更新链。
- 控制板是预设、滑条、模式切换的唯一输入 owner。文字层不接收命中输入。

## B 的适用范围与待验证项

当前验收针对 Cozy 环境中、视频内部的伪弹幕和伪字幕。B 关闭了文字场景网格
自己的开孔与深度写入，可能依赖视频已打开的显示区域；文字越出视频、视频隐藏、
前景菜单/手/控制器遮挡，以及不同环境和系统版本都需分别验证。
每次重新创建或 reshape 覆盖层后必须重新应用 B。保留网格和文字合成层意味着
此方案不是移除面板，也没有证明能减少纹理更新或合成开销。

## 后续替换主线的边界

后续独立变更应将“视频最终参数直接创建 + 保留文字 UI + 中央深度修正 + B”
接入产品已有播放、输入和生命周期 owner。生产中的动态加载、真实弹幕/字幕、
舞台缩放/曲率/抓取、遮挡、隐藏恢复与 Surface 交接均需重新验收。
不能仅合并调试 Activity 就称为完成主线替换，也不要同时保留旧的独立文字开孔。
