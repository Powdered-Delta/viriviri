# 右 Context rail：分P、合集与相关推荐

本轮将正式入口的 mode_panel 从调试占位替换为 ImmersiveRightPanel。
依据是 Penpot handmade（复制）的 W3 right_rail：固定40dp的“合集／相关视频”标签，
下方滚动列表，缩略图、标题及右对齐时长，没有 footer。

Penpot 是布局参考；实际信息密度和可读性以使用需求及头显验收为准。
相关视频与合集视频共用横向卡片：16:9封面叠加时长、两行标题、UP主、播放量与弹幕数。
合集标题／分组显示集数，当前视频突出“正在播放”。分P保持紧凑行。
计数复用浏览页的万／亿格式，缺失值显示“--”，不伪造为零。

两个tab分别持有滚动状态，切换tab保留各自位置；换BV时重置两份列表位置，保留所选tab。
右rail封面由进入组合的条目请求，缓存命中回填界面；被淘汰后滚回可重新加载。
加载中／缺图／失败分开显示，失败封面可点击重试，封面重试不触发选片。
下载最多4路并发，同URL在途请求独立于LRU去重，一次下载用于读尺寸和采样解码。
合集采用各集自己的封面；缺失时不挪用另一BV的封面。

[已读取的 Penpot 画板](https://penpot.890016.xyz/#/workspace?team-id=40366141-032f-816b-8008-c31e9bcd5e32&file-id=4bfed831-199b-81b9-8008-c43c2f7fc59b&page-id=40366141-032f-816b-8008-c3206735df70&board-id=9acc7b8f-145d-80d8-8008-c61e570b3608)。

## 行为

- 合集 tab 展示当前稿件的分P和UGC合集分组；点击分P使用该项cid播放，当前项高亮。
- 相关视频来自当前BV的相关推荐接口，不复用首页推荐充当结果。
- 点选合集或推荐视频切换媒体，保留原中心浏览来源和滚动位置。
- 单P且没有合集时显示空态；详情和推荐分别加载，分别提供失败重试。
- 仍由进程共享播放器播放；质量切换和播放失败重试保留当前分P的cid。
- 弹幕来源同样使用该cid；同BV切P会重建对应弹幕运行时。
- 不引入自动连播、队列接管或用户自建跨UP播放列表。

## 空间与所有权

复用 mode_panel、既有舞台父节点、静态位置、深度、可见性和命中策略。
注册改为 ComposeViewPanelRegistration；没有新增Spatial实体或视频Surface。
画布从280×464@600改为361×464@800，匹配相同0.70×0.90m物理形制的左 rail，
修正设计稿指出的横向拉伸。

ViriViriAppState拥有加载、重试和选片，Compose仅持有tab等视觉状态。
详情和相关推荐请求带代次与当前BV检查，取消或迟到的旧请求不能覆盖新视频。
UGC合集数据来自详情ugc_season.sections；分P来自pages，保留明确cid和顺序。

原产品显示设置移至Transport“设置”：显示比例、画布预设、恢复平面、重置高度、2D入口。
连续缩放仍可通过既有摇杆调节。原右rail的遥测和调试滑条退出主体；
弹幕Z、合成顺序和舞台遮挡保护通过现有手腕调试入口访问。
旧mode_panel.xml资源不再注册为运行时内容。

## 验证边界

必须检查真实多P视频的P2/P3画面与弹幕，合集中其他BV和相关推荐的切换，
空态、失败重试、连续快速换片后的旧请求隔离，以及Transport／手腕菜单入口。
Penpot稿件通过浏览器AX与截图实读；未修改设计文件。
本机公开接口探测中，相关推荐返回code=0、40项；详情探测HTTP412。
详情使用既有播放解析已经使用的相同接口，不将本机探测失败写成联调通过。

本轮不修改视频几何更新方式。[PLAYBACK-001](playback-known-issues.md)
仍为已知bug，延后到快进／快退阶段处理。
构建产物保持app/build/outputs/apk/debug/app-debug.apk；头显验收另行进行。
